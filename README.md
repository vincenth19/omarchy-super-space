# Super Space

Spotlight for [Omarchy](https://omarchy.org) that understands meaning, fully
local. Super+Space searches apps, settings, files and the text inside them,
photos, moments in videos, spoken words, song lyrics, clipboard and emoji, and
answers maths, units, currency and time zones. One on-device model,
EmbeddingGemma 2, covers text, images and audio. Runs on a Raspberry Pi 5.

Work in progress for the Omarchy meetup on 20 October 2026. See DESIGN.md.
